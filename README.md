# LINE スタンプメーカー

ブラウザだけで **LINE スタンプ（LINE Creators Market 規格）** を作成し、申請用 ZIP を書き出せる Web アプリです。
画像はすべてブラウザ内で処理され、外部のサーバーには送信されません。

## できること

| 機能 | 内容 |
| --- | --- |
| 画像の取り込み | 複数枚をまとめて追加／ドラッグ＆ドロップ。PNG・JPEG・GIF・WebP・BMP に対応 |
| 背景の透過 | 取り込み時に単色背景を自動で透明化。さらに「自動選択（マジックワンド）」「消しゴム」「復元ブラシ」で仕上げ |
| 白フチ | スタンプらしいフチ取りを太さ・色指定で追加（距離変換による滑らかなフチ） |
| 文字入れ | 商用利用可の日本語フォント 13 種、縁取り、回転、縦書き、改行、よく使うセリフ 40 種 |
| 一括操作 | 空のスタンプにセリフを一括入力、フチ・文字スタイルを全スタンプへ適用 |
| 配置 | ドラッグで移動、ハンドルで拡大縮小・回転、「ぴったり合わせる」で余白込みの自動フィット |
| 規格チェック | 個数（8/16/24/32/40）、サイズ、偶数 px、透過、1MB 以下、余白 10px、小さすぎを自動チェック |
| 書き出し | `01.png`〜`40.png`（370×320）、`main.png`（240×240）、`tab.png`（96×74）を ZIP で出力 |
| プレビュー | LINE のトーク画面に近い見た目・実寸（画像の半分）で確認 |
| 保存 | ブラウザに自動保存。バックアップファイルで他の端末へ移動も可能 |
| アプリ化（PWA） | ホーム画面・デスクトップにインストール可能。一度開けばオフラインでも作成・書き出しOK。新バージョンは通知から更新 |
| その他 | 元に戻す／やり直す（Ctrl+Z / Ctrl+Shift+Z）、矢印キーで微調整、スマホ対応 |

## 使い方

1. 左の「📁 画像をまとめて追加」でイラストを読み込む（背景は自動で透明になります）
2. 必要に応じて「🪄 背景を消す・整える」で消し残しを修正
3. 「＋ 文字を追加」や「💬 空のスタンプにセリフを入れる」でセリフを入れる
4. 「✨ ぴったり合わせる」で大きさを整える
5. 「👀 プレビュー」で確認し、「📦 書き出し」で ZIP をダウンロード
6. [LINE Creators Market](https://creator.line.me/ja/) の「スタンプ画像」から ZIP をアップロード

## アプリとしてインストール（PWA）

- **パソコン（Chrome / Edge）・Android**：メニュー →「📲 アプリとしてインストール」、またはアドレスバーのインストールボタン
- **iPhone / iPad**：Safari の共有ボタン →「ホーム画面に追加」

一度開くとアプリ本体がキャッシュされ、オフラインでも使えます（フォントは一度表示したものがキャッシュされます）。
新しいバージョンを公開すると画面下に「更新する」が表示され、作業内容を保存してから更新します。

## 開発

```bash
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm test           # ユニットテスト（Vitest）
npm run build      # 型チェック＋本番ビルド（dist/）
```

技術構成：Vite + React + TypeScript。画像処理（背景除去・フチ取り・外接矩形）は `src/lib/pixels.ts` に Canvas 非依存の純粋関数としてまとめ、テストしています。

```
src/
  lib/
    spec.ts       LINE の規格値（サイズ・個数・容量）
    pixels.ts     背景除去・フチ取り・距離変換などのピクセル処理
    render.ts     スタンプの描画（画像・文字・フチ）と当たり判定
    exporter.ts   ZIP 書き出し・main/tab 画像生成
    validate.ts   規格チェック
    storage.ts    IndexedDB への自動保存・バックアップ
  components/     画面（一覧・キャンバス・プロパティ・各ダイアログ）
```

## 公開（GitHub Pages）

`main` ブランチに push すると GitHub Actions がテスト・ビルドし、GitHub Pages に公開します。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。

## 注意

- フォントはすべて SIL Open Font License の Google Fonts で、LINE スタンプの販売に使用できます（初回表示時にインターネット接続が必要です）。
- 他人の著作物・写真・キャラクターを無断で使用したスタンプは審査に通りません。
- 規格は LINE Creators Market の[制作ガイドライン](https://creator.line.me/ja/guideline/sticker/)に基づいています。変更される場合があるため、申請前に最新の内容をご確認ください。
